=== Findings ===
Strategy A slips (violation under FULL guard) at ages: [0.5, 1.0, 1.5, 1.9]
Strategy A caught (prevented) at ages: [2.1, 2.5, 3.0]
Static full guard: catches the attack iff stale age >= ~2.1s (the freshness budget 2.0s) -> residual window ~2.0s.
Challenge guard (M1.1): still slips only at ages <= heartbeat; slips at [0.1, 0.2]
  -> residual window shrinks from the budget (2.0s) to the heartbeat (0.25s), ~8x.
Strategy B: delaying the guard re-read only makes it staler -> guard blocks;
targeting the re-read does not help (delay-only cannot make a value fresher).

METHOD (contribution): the static budget conflates transport-latency tolerance
with staleness tolerance; challenge-response freshness separates them, requiring
each critical fact to be affirmed AFTER the action is proposed (tolerance = sensor
heartbeat). A delay-only adversary cannot replay a stale value with a post-challenge
affirmation, so the residual attack window collapses to the sensor heartbeat -- a
hard physical floor, not the (tunable, usability-costly) freshness budget.
